Test a completed redemption retry with the same key, or send two simultaneous requests to check one-time card redemption.

Request credentials

POST /api/redeem/top-up-account

The wallet for this phone number receives the top-up.

Used only by the two-phone, same-PIN test.

Enter one bearer token per user. Each user sends five failed attempts from this same browser IP, followed by one IP-limit check.

The repeated-PIN test may redeem an active card on its first request. These tests can block the user for 30 minutes or the IP for one hour.
